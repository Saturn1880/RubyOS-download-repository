# 🎓 Ruby AI — Coding & Assistant School Pack (v1.11)

This is the "school" Wyatt asked for: everything Ruby AI was taught, in one place.

## How Ruby "learned" from this pack — honestly

A web page can't unzip a file and study it by itself, and Ruby AI is deliberately
built with **no external AI APIs** — so the teaching was done the real way:
the lessons, decision rules and the complete app templates in this pack were
**compiled into Ruby herself** (the `RubyApps` generator library and the
`RubySchool` lessons inside `RubyAI-v1.11.html` / `src/ruby-core.js`).
This ZIP is the full school, readable by humans and reusable by anyone building
their own AI on the Ruby Architecture: teach your AI the same way by giving it
complete templates and decision rules, not fragments.

## The templates (all complete, all working)

- `desktop-os.html` — a Windows-style desktop: clickable icons, draggable windows, taskbar, Start menu, live clock, Notepad / Calculator / Photos / Settings / Browser apps inside
- `game-gem-collector.html` — canvas game: move, collect, dodge, score, lives, levels, pause, difficulty, touch controls
- `calculator.html`, `todo-list.html` (saves), `paint.html` (save as PNG), `chat-buddy.html`, `website-about-cats.html`, `starter-page.html`

## Ruby's golden rules (from CODE_SCHOOL.md)

1. A big ask gets a big file — a desktop is hundreds of lines, and that's correct.
2. Default file type is HTML; the type the person names is the type they get.
3. No placeholders, no fake buttons — if it looks clickable, it works.
4. Never fake an answer — say so, and offer to learn it.
