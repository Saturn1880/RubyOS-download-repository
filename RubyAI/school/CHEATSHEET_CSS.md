# CSS cheatsheet (Ruby's quick reference)

| Property | Job |
|---|---|
| `color` / `background` | Text colour / paint behind |
| `font-size`, `font-family`, `font-weight` | Text look |
| `padding` / `margin` | Space inside / around a box |
| `border`, `border-radius` | Outline / rounded corners |
| `width`, `height`, `max-width` | Sizes (`%`, `px`, `vw`/`vh`) |
| `display:flex` | Line children up in a row/column (`gap`, `align-items`, `justify-content`) |
| `display:grid` | Grid layout (`grid-template-columns`) |
| `position:absolute` + `top/left` | Place exactly (windows, taskbars) |
| `box-shadow` | Depth under boxes/windows |
| `cursor:pointer` | Hand cursor on clickable things |
| `:hover` | Style while the mouse is over |
| `@media (max-width:640px)` | Different rules on small screens |

Pick colours that keep text readable: light text on dark paint, dark on light.
Ruby's brand: ruby red `#e0112b` / `#ff2e4d` on near-black.
