## About RubyOS

RubyOS is a complete desktop-style operating system packed into a single HTML file (about 1.65 MB). It has:

- A desktop, launcher and search with **29 apps**
- A Game Launcher with 24 games, including Ruby Clicker and Ruby Surfers, plus Chess and Checkers with champion-level AI
- A movable weather widget, Ruby Earth, themes and wallpapers
- A built-in update system: an update counter, an exactly one-minute update check screen, a red "Sorry, RubyOS has hit a roadblock" screen, and automatic fallback to your last working version if an update fails

It runs on phones, Chromebooks and computers — anywhere a modern browser runs. It was made to run on a Samsung Galaxy S20 Ultra and a Chromebook, and it does.

## Why it was created

RubyOS is a personal project by **Wyatt (Saturn1880)**. The idea: instead of being stuck with whatever operating system a device ships with, build your own — one that you control completely, that runs on the devices you already have, and that lives in a single file you can carry anywhere and share with anyone. No installs, no accounts, no app store approvals. If you have a browser, you have RubyOS.

## How it was created

RubyOS is written in **HTML, CSS and JavaScript**, all in one file. Wyatt designs the features, decides what goes in each version, and tests releases on his own phone and Chromebook before they are published here on GitHub.

AI assistants have helped build parts of it along the way — Milo helps edit, test and publish releases, the Ruby AI assistant app was built with Gemini, and a standalone Ruby AI was built with Claude. Every version is checked before it is released, and older versions stay in the [ruby-updater](https://github.com/Saturn1880/ruby-updater) repository.

## How to install

1. Download **RubyOS-v5.9.25.html** from this repository.
2. Open the file in any modern browser (Chrome, Edge, and others work).
3. That's it — RubyOS starts. There is nothing to install.

Tips:

- Bookmark it or add it to your home screen so it feels like a real installed OS.
- Your settings and saves live in the browser you open it with, so use the same browser each time.
- To update: when a new version is released, download the new file. RubyOS counts your updates, checks each update for one minute before installing it, and automatically falls back to your last working version if anything goes wrong.
